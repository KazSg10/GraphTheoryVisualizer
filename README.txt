Open the project in VS Code
Ensure JDK 21 or higher is installed 
Also install extension pack for Java
In the project explorer, go to src/com/server and right click WebServer.java, and click Run Java to start the web server
Once server is running, find a log like this in console/terminal "URL to access webapp -> http://192.168.1.194:8908"
Please note, IP address will be different on different computers
Run the URL in a browser and wait a few minutes for the webapp to load
