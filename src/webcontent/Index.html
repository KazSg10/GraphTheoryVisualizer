AQA Graph Theory Algorithms Visualizer

Welcome to the AQA Graph Theory Algorithms Visualizer

This webapp is for you to simulate the Graph Theory Algorithms in the AQA Specification (4.3.1.1 and 4.3.6.1), which are: DFS (Or Depth First Search/Traversal), BFS (Or Breadth First Search/Traversal) and Dijkstra's Shortest Path Finding Algorithm. Here you can see how a graph is traversed, how each data structure and abstract data type involved in that algorithm is updated, and the step by step highlighting of pseudocode as the algorithm progresses

Custom Graph

Creating A Graph

After selecting one of the algorithm's tabs at the top, you can create a custom graph by typing the information of the edges. This will entail typing the name of the first node, the name of the second node, the direction of the edge between the two nodes, the weight if you are trying to simulate the Dijkstra Algorithm, and one source node. To add a new row for a new edge, please click Add New Row, and when you are happy with your graph, click Submit.

Direction

For the direction option, if you would like the path to be bidirectional between the two nodes, select bidirection. If you would like the path to only go from node 1 to node 2, select unidirection.

Validating Values

Make sure all the cells for all the rows are filled with the values for the graph you would like. As well as this, if you are similating Dijkstra's Algorithm, Make sure the value of the weight is an integer (or a decimal with 0s after the decimal point). Finally, ensure that the source node is in the graph.

Using A Saved Graph

If you would like to simulate the algorithm on a graph you have created and saved previously, you would have the json form of the graph, and you can paste this into the textbox next to the add row button, and then click submit.

Simulating Algorithm

After clicking submit, you would be able to say 3 boxes, one with the graph, another with the abstract data type or data structure involved in the algorithm and another with the pseudocode. To start the simulation you can click Play. To go back to the custom graph making page, you can click Home. If you want to save this graph, you can click Save Graph to download the text file with the json form of the custom graph you created. Additionally you can also control the speed by changing the position of the Speed Slider.
