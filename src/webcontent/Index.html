What is a graph?


A graph is an abstract data type (a conceptual model which uses primitive data structures for specific operations) A graph is made up of nodes which are connected by edges

Properties of Graphs

A weight (or cost) is a value associated with an edge, which could represent a value such as distance or time

A direction is the way an edge goes from one node to another node.

           → A bidirection is when the edge can be travelled along both ways

           → An unidirection is when the edge can only be travelled on one way

Traversal

A traversal is a systematic visit to each node in a graph (or at least part of the graph if it is disconnected)

Depth First Traversal

Depth-First Traversal (or Depth-First Search) is a graph traversal algorithm, in which the algorithm starts at a source node, and then explores as far as possible along each branch before backtracking to previous nodes to explore other branches. This algorithm uses

Dijkstra's Shortest Path Finding
